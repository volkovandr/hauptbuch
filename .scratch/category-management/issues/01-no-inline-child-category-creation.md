# No quick way to add a child category from its parent

Status: needs-triage
Severity: medium
Area: Category management (category list/edit screens)

Creating a child category today means picking the parent from a dropdown during creation. Request:
a button next to each parent category in the list that opens a minimal create form — just a name
field — which creates the new category under that parent, inheriting the parent's type
automatically (see the related type-inheritance ask, category-management issue 02).
