# Category list has no collapse/expand for parent categories

Status: needs-triage
Severity: minor
Area: Category management (category list screen)

The category list always renders the full tree expanded. For a taxonomy with many subcategories
this gets long. Request: let a parent category collapse/expand its children, the way many
tree-view UIs do.
