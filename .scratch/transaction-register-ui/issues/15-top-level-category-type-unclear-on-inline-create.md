# Inline top-level category creation doesn't make income vs. expense clear

Status: needs-triage
Severity: minor
Area: Transaction register — entry (category picker, create-new)

Creating a new top-level category inline (no existing parent matched) doesn't make it obvious
whether it becomes an income or expense category. Request: either ask explicitly, or support a
naming convention that signals it — e.g. typing something like "Income - Found on the street"
could be read as a hint to create a new top-level *income* category named "Found on the street".
