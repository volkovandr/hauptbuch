Status: ready-for-agent
Category: enhancement
Severity: low
Area: Landing page (`ledger` template), new stats surface in `analytics`

A single encouraging line on the landing page summarising how much the book tracks: time span,
transaction count, analyzed-receipt count and receipt-image storage size.

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement
**Summary:** Add a muted one-line "tracking stats" summary to the landing page, above the Balances
panel, served as an htmx fragment from a new stats surface in the `analytics` module.

**Current behavior:**
The landing page shows only the greeting and lede. There is no transaction-count, receipt-count, or
storage surface anywhere. The `analytics` module exists but is empty (`package-info.java` only) and
depends on nothing. `LandingController` is in `ledger`; `ledger` cannot read `receipts` data because
`receipts` already depends on `ledger` (the reverse edge would be a cycle `verify()` forbids).

**Desired behavior:**

*Placement and shape*
- One muted line (a `<p class="muted">`-style element, not a `.panel`), rendered directly under the
  landing page's lede and **above** issue `01`'s Balances panel — it reads as a continuation of the
  app identity. A one-line shift of the panel when the fragment loads is acceptable.
- Delivered as an htmx fragment: `landing.html` contains a container with `hx-get` to the new
  endpoint and `hx-trigger="load"`. `LandingController` stays in `ledger` and only renders the
  container.

*Content* — the line reads:

> Keeping track of your finances for **2 years and 8 months** — **1.234 transactions**, **800
> receipts analyzed** (**2,5 GB**).

- **Duration:** from `min(transaction.date)` where `deleted_at is null` to today, rendered years +
  months, days dropped, via `java.time.Period`:
  - `2 years and 8 months`
  - `1 year and 1 month` (singular)
  - `3 years` (omit "and 0 months")
  - `7 months` (omit "0 years and")
  - `less than a month` (same year-month)
- **Transaction count:** `count(*)` of `transaction` where `deleted_at is null`, any `lifecycle`.
  Opening-balance transactions are included. German thousands separator via the shared formatter.
- **Receipt clause:** count of receipts where `deleted_at is null` and `parse_raw is not null`
  ("analyzed" = the parse produced a response; excludes `new`, `pre_processed`, `failed`). Followed
  by the storage size in parentheses.
- **Storage size:** total bytes of the receipt image store — a filesystem walk of the configured
  `hauptbuch.receipts.storage-root`, summing file sizes. Humanised with **decimal (SI) units**,
  `B` / `kB` / `MB` / `GB`, **one decimal place** (e.g. `2,5 GB`, `847,0 MB`). Expose it from the
  `receipts` module (e.g. a method on `ReceiptStorage`), not by reaching into the filesystem from
  `analytics` directly.

*Empty states*
- Base currency not set / fresh book → the fragment container is not rendered at all.
- Zero live transactions → the endpoint renders nothing (no anchor for "for X").
- Transactions exist but zero analyzed receipts → **drop the receipt clause**:
  `Keeping track of your finances for 2 years and 8 months — 1.234 transactions.`

**Key interfaces:**
- `analytics` module gains dependencies on `ledger` and `receipts` (both clean — nothing depends on
  `analytics`). `ApplicationModules.verify()` must stay green.
- A new `analytics` service assembling the stats model from: earliest transaction date + transaction
  count (a `ledger` read API), analyzed-receipt count + total storage bytes (a `receipts` read API).
- A new `analytics` controller serving the fragment (choose a stable path such as
  `/overview/tracking-stats`), returning a Thymeleaf fragment with the rendered line, or an empty
  body for the "nothing to show" cases.
- `ledger` read API — a method returning `min(transaction.date)` (ignoring soft-deleted) and a
  method returning the live transaction count. May be new methods on an existing `ledger` service /
  repository.
- `receipts` read API — analyzed-receipt count (`parse_raw is not null`, not soft-deleted) and total
  image-store size in bytes.
- `landing.html` — adds the fragment container above the Balances panel.
- Two small formatters (duration → words, bytes → SI string) — pure functions, wherever the module's
  conventions put such helpers.

**Acceptance criteria:**
- [ ] `./gradlew check` fully green, including `ApplicationModules.verify()` with the new
      `analytics → ledger` and `analytics → receipts` edges.
- [ ] Unit tests: the duration formatter (every singular/plural/`3 years`/`7 months`/`less than a
      month` case); the byte humaniser (`B`/`kB`/`MB`/`GB`, one decimal, decimal units); the stats
      service (drops the receipt clause when analyzed count is 0; returns a "render nothing" result
      when there are zero live transactions).
- [ ] Integration tests: `min(date)` ignores soft-deleted transactions; transaction `count` ignores
      soft-deleted; analyzed-receipt `count` keys on `parse_raw is not null` and ignores
      soft-deleted; `ReceiptStorage` size method sums a temp directory's files correctly.
- [ ] Integration test on the fragment controller via MockMvc: renders the full line; renders the
      no-receipt-clause variant; renders empty for zero transactions; landing page carries the
      `hx-get` + `hx-trigger="load"` container above the Balances panel; container absent before
      base currency is set.
- [ ] Copy is exactly the agreed sentence structure; English only; German number formatting via the
      shared utility.
- [ ] Consistent with the `CONTEXT.md` "Tracking stats" term added during triage.

**Out of scope:**
- Any per-transaction or per-receipt detail, drill-down, or charting.
- AI-spend / token-cost figures (the telemetry columns exist but are not part of this line).
- A `size_bytes` column on `receipt` or a backfill (the filesystem walk is the chosen approach;
  revisit only if measured slow).
- Caching the walk result.
- Moving `LandingController` out of `ledger`, or server-composing the line without the fragment.
- The Balances panel (issue `01`).

- No cheerful sign-off — sentence ends at the parenthesis.

- Empty states: no fragment pre-base-currency; nothing rendered at zero transactions; drop the
  receipt clause at zero analyzed receipts.

  fragment controller. No `sqlLogicTest` — the queries are one-table scalar aggregates.
