# Register zebra-striping contrast is too strong

Status: needs-triage
Severity: low
Area: General UX — register row striping (`register.css`)

The light/dark contrast between alternating (zebra) register rows is bigger than the contrast
between different row hues used elsewhere (e.g. pending-review muting), which makes the register
read as more visually busy/confusing than intended. Request: soften the zebra contrast.
