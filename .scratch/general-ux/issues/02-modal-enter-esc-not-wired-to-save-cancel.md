# Modal dialogs don't respond to Enter/Esc as Save/Cancel

Status: needs-triage
Severity: low
Area: General UX — modal dialogs

Modal dialogs (e.g. the receipt delete-ladder dialogs) don't respond to the keyboard: Enter should
accept the modal's primary action as if its Save/confirm button were clicked, Esc should dismiss
it as if Cancel were clicked. Request: wire both across the app's modal dialogs.
