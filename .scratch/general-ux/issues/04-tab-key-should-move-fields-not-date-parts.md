# Tab key walks date sub-components instead of moving to the next field

Status: needs-triage
Severity: low
Area: General UX — date input (entry dock and elsewhere)

When entering a date, Tab currently moves between the date's day/month/year sub-components — but
Right arrow already does that, making Tab redundant for it. Request: Tab should move to the next
form field instead, matching normal form-navigation expectations; Right arrow keeps handling
movement within the date component.
